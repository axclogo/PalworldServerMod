# 世界地图去雾

玩家包默认启用。打开大地图，查看尚未探索的地形。传送点和剧情云由游戏管理。

游戏在初始化和切换地图时按区域登记地图主体。玩家端直接在这些主体上隐藏 `Image_MapMask`，地图重新应用默认遮罩时也处理。平时游玩没有地图定时器。此功能只改界面显示，玩家的探索记录仍由原版管理。[社区地图控件记录](https://github.com/Pixnop/CairnMap/blob/930d77e2d3757235a7beb977057ee2ce32776d07/UPDATE-1.0.md#L84-L95)

排查时，在显示异常的大地图上按 Ctrl+F8。打开玩家端的 `UE4SS.log`，查找 `[PalMapReveal]`。`Live maps: 0` 表示没有定位到世界地图实例；找到窗口但 `hidden Image_MapMask layers: 0` 表示没有找到并隐藏预期的图层。已报告隐藏图层而画面仍有普通探索雾时，保留日志与该位置的截图。停用时退出游戏，将 `PalMapReveal` 移出活动 Mods 目录。
