幻兽帕鲁 客户端安装说明（小白版）

不熟悉文件操作就照着一步一步复制，全程只用「复制 / 粘贴 / 合并文件夹」。
装完在游戏里能看到：石像最高 80 级、竞技场多 14 件商品、地图没雾、钓鱼自动提竿、天擒鸟滑翔显示本体。

==================================================
准备
==================================================
1. 正版 Steam《幻兽帕鲁》，并且至少启动过一次（让游戏先生成目录）。
2. 本文件夹里的 3 个压缩包：
   - UE4SS-Palworld-g2281fa31.zip   （前置，必须这个版本）
   - PalSchema_0.6.71.zip            （前置）
   - 幻兽帕鲁-玩家端.zip              （本整合包）
3. 不要装「服务端」那个包，那是给服务器用的。

==================================================
第一步 找到「游戏根目录」
==================================================
Steam → 库 → 右键《幻兽帕鲁》→ 管理 → 浏览本地文件
弹出的文件夹就是「游戏根目录」，里面有 Palworld.exe。

下面所有路径都以这个目录开头，记作「游戏根目录」。
注意：是游戏根目录，不是 Pal\Binaries\Win64，别搞混。

==================================================
第二步 装 UE4SS（前置）
==================================================
1. 解压 UE4SS-Palworld-g2281fa31.zip，得到两个东西：
   - dwmapi.dll（一个文件）
   - ue4ss（一个文件夹）
2. 两个一起复制到：
   游戏根目录\Pal\Binaries\Win64\
   遇到「是否替换」选「替换」，「是否合并」选「合并」。

装对的话，这里应该有两个文件：
   ...\Pal\Binaries\Win64\ue4ss\UE4SS.dll
   ...\Pal\Binaries\Win64\ue4ss\MemberVariableLayout.ini

==================================================
第三步 装 PalSchema（前置）
==================================================
1. 解压 PalSchema_0.6.71.zip，得到一个 PalSchema 文件夹。
2. 整个复制到：
   游戏根目录\Pal\Binaries\Win64\ue4ss\Mods\
3. 复制完里面必须有这个文件（最容易漏）：
   ...\ue4ss\Mods\PalSchema\dlls\main.dll

==================================================
第四步 装整合包
==================================================
解压 幻兽帕鲁-玩家端.zip，会看到 Pal 和 Mods 两个文件夹。

A. 把解压出来的 Pal 文件夹
   复制进「游戏根目录」，提示合并选「是」。
   装好后应该有：
   游戏根目录\Pal\Content\Paks\~mods\PalSoulCap80_P.pak

B. 打开解压出来的 Mods 文件夹，里面有三个文件夹：
   PalFishingWin、PalGliderVisual、PalMapReveal
   把它们复制到：
   游戏根目录\Pal\Binaries\Win64\ue4ss\Mods\
   同名选「合并」，同名文件选「替换」。

==================================================
第五步 四行自查（装完必看）
==================================================
打开下面四个位置，能一一对应就没问题：

1. 游戏根目录\Pal\Binaries\Win64\ue4ss\UE4SS.dll
2. 游戏根目录\Pal\Binaries\Win64\ue4ss\MemberVariableLayout.ini
3. 游戏根目录\Pal\Binaries\Win64\ue4ss\Mods\PalSchema\dlls\main.dll
4. 游戏根目录\Pal\Content\Paks\~mods\PalSoulCap80_P.pak

缺哪个就是哪一步没做对，回去补上。

==================================================
第六步 进游戏
==================================================
单机：直接从 Steam 启动就能玩。
联机：游戏内「加入多人游戏」→「通过 IP 连接」，填服务器地址和端口，例如
   123.45.67.89:8211

==================================================
装完怎么确认真的生效
==================================================
1. 石像：拿一只帕鲁升一项 20→21，提示需要「10 个究极帕鲁之魂」→ 生效
2. 竞技场：商品列表多出 14 件（传说 + 九种帝王 + 四个自定义）→ 生效
3. 地图：打开大地图，没去过的区域也能看到地形 → 生效
4. 钓鱼：抛竿后咬钩自动提竿 → 生效

==================================================
常见问题
==================================================
Q：游戏启动直接闪退？
A：多半是 UE4SS 版本错了。必须用 UE4SS-Palworld-g2281fa31.zip，
   用上游版或别的版本会崩。

Q：能进游戏，但石像还是最高 20 级？
A：第四步 A 没做对，检查 ...\Pal\Content\Paks\~mods\PalSoulCap80_P.pak 是否存在。

Q：商店没有新商品、手术台没有「传说」？
A：第三步漏了 dlls\main.dll，或第四步的 Pal 文件夹没合并。

Q：没有去雾 / 钓鱼不会自动提竿？
A：第四步 B 的三个文件夹没放进 ...\ue4ss\Mods\。

Q：连服务器提示版本不符或客户端 mod 不允许？
A：两端游戏版本要一致；服务器需要允许客户端 mod（服主设 bAllowClientMod=True）。
   本机只需装客户端包，不要装服务端包。

Q：以后更新怎么弄？
A：重复第二、三、四步，全部覆盖；不需要先删旧文件。
   如果旧包里出现过 PalSchema\mods\PalSoulCap80 这个文件夹，把它整个删掉。
